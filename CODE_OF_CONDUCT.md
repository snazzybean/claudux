# Code of Conduct

## The short version

Be decent to each other. This is a spare-time project; everyone here is
spending time they didn't have to.

## What that means

* Assume the other side is trying to help. A bug report written in a hurry
  is still someone taking the time to write it.
* Criticize the code, the design, the decision — not the person who made it.
* Harassment, insults, and personal attacks are not welcome here, and
  neither is unwanted contact after someone has asked you to stop.
* No one owes you a fix, an answer, or a schedule. Asking is fine, pressing
  is not.
* English in issues, discussions and pull requests, so everyone can follow
  along.

## Scope

This applies in the issue tracker, in discussions, in pull requests and
anywhere else this project is being worked on.

## If something goes wrong

Report it through GitHub's **Report a vulnerability** button on the
repository's Security tab. It opens a private thread with the maintainer,
which is the only private channel this project has — the same one
`SECURITY.md` points at.

Expect an answer within a week. What follows is a decision: a warning, a
removed comment, or a block from the repository, depending on what happened.
